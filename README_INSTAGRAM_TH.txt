CANDY BAKED — ชุดหน้าสินค้าสำหรับ Instagram

ไฟล์ชุดนี้แก้ปัญหา “ไม่ใช่หน้าสินค้า” โดยเพิ่มหน้าสินค้าเฉพาะ 1 รายการต่อ 1 URL จำนวน 20 รายการ

ไฟล์สำคัญ
- products/*.html: หน้าสินค้าเฉพาะรายชิ้น
- products/index.html: หน้ารวมลิงก์สินค้า
- meta-catalog.csv: Data Feed สำหรับ Meta Commerce Manager
- sitemap-products.xml: Sitemap ของหน้าสินค้า
- INSTAGRAM_PRODUCT_URLS.txt: รายการ URL สำหรับคัดลอก

สำคัญ
1. ต้องนำไฟล์ทั้งหมดไปรวมกับไฟล์เว็บไซต์ปัจจุบัน แล้ว Deploy ขึ้นโดเมน candybaked.ogenicchocolate.com ก่อน
2. ห้ามอัปโหลด ZIP นี้แบบแทนที่เว็บเดิมหากไม่มีไฟล์เว็บปัจจุบันอยู่ใน ZIP
3. หลัง Deploy ให้เปิด URL ตัวอย่างและตรวจว่าแสดงชื่อ ราคา รูป และปุ่มสั่งซื้อ
4. จากนั้นคัดลอก URL หน้าสินค้าเฉพาะไปค้นหาใน Instagram เช่น
   https://candybaked.ogenicchocolate.com/products/original-shio-pan.html

หมายเหตุ: หน้าเว็บใช้การสั่งซื้อและรับข้อมูลการชำระเงินผ่าน LINE OA ตามระบบปัจจุบันของร้าน
